# おとや｜環境音ミキサー

音源ファイルを一切使わず、Web Audio API で環境音をリアルタイム合成する環境音ミキサーです。

| 項目 | 内容 |
|---|---|
| バージョン | 1.0.0 |
| 状態 | 公開中 |
| 稼働先 | [otoya.vercel.app](https://otoya.vercel.app)（Vercel、静的ホスティング） |
| 実装 | HTML / CSS / JavaScript（Web Audio API、外部リソース不使用） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## 📖 概要

ビルド不要の静的サイトで、PWA としてインストールもできます。音はすべてブラウザ上で合成するため、音源ファイルのダウンロードは発生しません。

## ✨ 機能

- **6種の環境音**（すべて合成音）
  - 🌧 雨：フィルタ済みホワイトノイズ
  - 🌊 波：ノイズにゆっくりした LFO で音量・フィルタを変調
  - 🍃 風：バンドパスノイズの中心周波数を LFO で揺らす
  - 🔥 焚き火：低いノイズ＋ランダムなパチパチ音
  - 🚃 電車：周期的な「ガタンゴトン」のリズムノイズ＋走行ノイズ
  - 🦗 夜の虫：高音サイン波の鳴き声をランダムな間隔・定位で再生
- 各サウンド個別の ON/OFF スイッチと音量スライダー（複数を同時に重ね掛け可能）
- 全体再生/停止ボタン（停止しても ON/OFF 設定は保持され、もう一度押すと再開）
- スリープタイマー（15分 / 30分 / 60分で自動停止、残り時間を分:秒で表示）
- プリセット3種：集中 / リラックス / 睡眠（各音の ON/OFF と音量の組み合わせ）
- 音量・ON/OFF 設定は localStorage に自動保存
- ダーク / ライトテーマの手動切り替え（既定はダーク、選択は保存される）

## 📝 使い方

1. `index.html` をブラウザで開く（または静的ホスティングに配置する）だけです。
2. 聴きたいサウンドのスイッチを ON にすると再生が始まります。スライダーで音量を調整できます（音量を上げると自動で ON になります）。
3. 「すべて再生 / すべて停止」ボタンで、ON になっているサウンドをまとめて再生・停止できます。
4. プリセットボタンを押すと、おすすめの組み合わせが一括で設定され、再生が始まります。
5. スリープタイマーを設定すると、指定時間後に自動で停止します。

## 📋 技術メモ

- 外部リソース不使用（フォントはシステムの日本語フォントスタック、ライブラリ不使用）
- 合成はすべて Web Audio API：ホワイトノイズバッファ＋ Biquad フィルタ＋ LFO が基本で、焚き火のパチパチ音と電車のリズムはインパルス列／リズムパターンを焼き込んだ AudioBuffer のループ再生、夜の虫はサイン波オシレータを setTimeout でスケジューリングしています
- 音量は知覚に合わせて `Math.pow(vol/100, 1.6)` のカーブでゲインに変換（マスター段で ×0.9）
- 全音源を最大音量で重ねても割れないよう、マスター段にしきい値 -2dB・比 20:1 のコンプレッサーを安全弁として挿入
- 開始・停止は短いフェードでつなぎ、クリックノイズを防ぎます
- 純粋ロジック（プリセット・音量変換・保存形式・タイマー表示）は `js/mixer-core.js` に分離し、`npm test` で検証しています
- PWA：`manifest.webmanifest` と `sw.js`（同一オリジン GET をキャッシュファーストで配信、キャッシュ名 `otoya-v1`）
- アイコンは角丸＋日本語1文字の PNG（192px / 512px）

## 📁 ファイル構成

```
index.html            画面
style.css             スタイル（ダーク/ライトテーマ）
js/mixer-core.js      純粋ロジック（プリセット・保存形式・音量変換など）
app.js                合成エンジンと UI ロジック
sw.js                 Service Worker
manifest.webmanifest  PWA マニフェスト
icons/                アイコン（192 / 512）
tests/                ユニットテスト（npm test）
```
